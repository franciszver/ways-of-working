# lean-max-effort

Discipline for producing frontier-quality output at minimum token cost — makes Sonnet and Opus plan, verify, and track requirements like a top-tier model at max effort, while cutting token waste that inflates the bill.

Runs every task through four phases: **Capture → Plan → Execute lean → Verify.** See `SKILL.md` for the full workflow.

## Install

Package as a Claude skill (`SKILL.md` with frontmatter `name`/`description`) and drop into your skills directory, or zip it as a `.skill` file for upload.
